  <name>Feature: URL Validation with SSRF Prevention</name>
  <files>src/urlValidation.ts, src/urlValidation.test.ts, vitest.config.ts, package.json</files>
  <behavior>
    Wave 0 setup:
    - Install vitest: `npm install -D vitest`
    - Create vitest.config.ts with default config (no special setup needed beyond Vite defaults)

    validateUrl(input: string) -> ValidationResult:
    - Empty string -> { valid: false } (no error message)
    - "ftp://example.com" -> { valid: false, error: "Only http and https URLs are supported" }
    - "https://example.com" -> { valid: true }
    - "http://example.com/path?q=1" -> { valid: true }
    - "not a url" -> { valid: false, error: "Invalid URL format" }
    - "https://localhost" -> { valid: false, error: "Local addresses are not allowed" }
    - "https://127.0.0.1" -> { valid: false, error: "Private network addresses are not allowed" }
    - "https://10.0.0.1" -> { valid: false, error: "Private network addresses are not allowed" }
    - "https://192.168.1.1" -> { valid: false, error: "Private network addresses are not allowed" }
    - "https://172.16.0.1" -> { valid: false, error: "Private network addresses are not allowed" }
    - "https://169.254.1.1" -> { valid: false, error: "Private network addresses are not allowed" }
    - "https://0.0.0.0" -> { valid: false, error: "Local addresses are not allowed" }
    - "https://[::1]" -> { valid: false, error: "Local addresses are not allowed" }
    - "http://2130706433" -> { valid: false, error: "Numeric IP addresses are not allowed" }
    - "http://0x7f000001" -> { valid: false, error: "Hex IP addresses are not allowed" }
    - "https://example.com;rm -rf /" -> { valid: false, error: "URL contains invalid characters" }
    - "https://example.com|cat /etc/passwd" -> { valid: false, error: "URL contains invalid characters" }
    - "https://example.com$(whoami)" -> { valid: false, error: "URL contains invalid characters" }
    - Input with leading/trailing whitespace should be trimmed before validation
  </behavior>
  <implementation>

    2. Create vitest.config.ts: `import { defineConfig } from 'vitest/config'; export default defineConfig({ test: {} });`

    4. Run tests (RED) -- all should fail

       - SHELL_META_RE for metacharacter rejection (SECR-02)

       - Protocol check for http/https only (FETCH-01)
       - BLOCKED_HOSTNAMES set for localhost, 0.0.0.0, [::1], [::ffff:127.0.0.1]

<feature>
  <name>Feature: Fetch Utilities (curl building, HTML parsing, bot detection)</name>
  <files>src/fetchUtils.ts, src/fetchUtils.test.ts</files>
  <behavior>
    fetchHtml(shell, url) -> { html, headers }:
    - Calls shell.exec('curl', [...args, url]) with discrete arguments (SECR-01)
    - Args include: -s, -L, --max-time 30, --max-redirs 5, --max-filesize 5000000, -A (browser UA), -D /dev/stderr
    - shell.exec called with { timeout: 35000 }
    - exit_code 0 -> returns { html: stdout, headers: stderr }
    - exit_code 28 -> throws "Site took too long to respond"
    - exit_code 63 -> throws "Response too large"
    - other non-zero -> throws with stderr message

    fetchCss(shell, url) -> string:
    - Similar to fetchHtml but simpler -- fetches a single CSS URL
    - Returns stdout as CSS content string
    - Same timeout and error handling

    extractStylesheetUrls(html, pageUrl) -> string[]:
    - Parses HTML with DOMParser, finds link[rel="stylesheet"] elements
    - Resolves href relative to pageUrl using new URL(href, pageUrl)
    - Caps at 20 stylesheets max
    - Skips malformed URLs (no throw)
    - '<link rel="stylesheet" href="/css/main.css">' with pageUrl "https://example.com/about/" -> ["https://example.com/css/main.css"]
    - '<link rel="stylesheet" href="//cdn.example.com/style.css">' with pageUrl "https://example.com" -> ["https://cdn.example.com/style.css"]
    - No link tags -> empty array

    detectBotProtection(html, headers) -> BotDetectionResult:
    - cf-mitigated: challenge header -> { isBlocked: true, provider: "Cloudflare" }
    - HTML contains __cf_chl -> { isBlocked: true, provider: "Cloudflare" }
    - Title "Just a moment" -> { isBlocked: true, provider: "Cloudflare" }
    - HTML contains _abck -> { isBlocked: true, provider: "Akamai" }
    - HTML contains g-recaptcha -> { isBlocked: true, provider: "CAPTCHA" }
    - Normal page -> { isBlocked: false }
  </behavior>
  <implementation>
    1. Write failing tests in src/fetchUtils.test.ts:
       - Mock shell.exec to verify curl args are discrete array elements (SECR-01)
       - Test error mapping for exit codes 28, 63, and generic
       - Test extractStylesheetUrls with various HTML fragments
       - Test detectBotProtection with Cloudflare headers, challenge HTML, Akamai markers, CAPTCHA markers, clean pages
       - Note: DOMParser is available in browser environment. For vitest, use jsdom environment for this test file: add `// @vitest-environment jsdom` pragma. Install jsdom: `npm install -D jsdom`
    2. Run tests (RED)
    3. Implement src/fetchUtils.ts following research code examples:
       - USER_AGENT constant with Chrome UA string
       - fetchHtml: builds curl args array (never interpolates URL), handles exit codes
       - fetchCss: similar but simpler (no header capture needed)
       - extractStylesheetUrls: DOMParser + querySelectorAll + URL resolution
       - detectBotProtection: checks headers and HTML content markers
       - Export BotDetectionResult interface
    4. Run tests (GREEN)
    5. Refactor if needed (ensure clean exports, consistent error messages)
  </implementation>
</feature>
