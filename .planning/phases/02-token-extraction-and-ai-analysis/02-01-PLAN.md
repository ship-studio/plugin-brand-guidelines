  <behavior>
    ## Color Extraction (extractColors)
    - Input: `string[]` (array of CSS text content)
    - Output: `RawColor[]` where `RawColor = { value: string, hex: string, varName?: string }`

    Cases:
    - `["a { color: #f00; }"]` -> `[{ value: "#f00", hex: "#ff0000" }]`
    - `["a { color: #ff0000; }"]` -> `[{ value: "#ff0000", hex: "#ff0000" }]`
    - `["a { color: #ff000080; }"]` -> `[{ value: "#ff000080", hex: "#ff0000" }]` (alpha stripped)
    - `["a { color: rgb(255, 0, 0); }"]` -> `[{ value: "rgb(255, 0, 0)", hex: "#ff0000" }]`
    - `["a { color: rgb(255 0 0); }"]` -> `[{ value: "rgb(255 0 0)", hex: "#ff0000" }]` (space syntax)
    - `["a { color: rgb(255 0 0 / 0.5); }"]` -> hex: "#ff0000" (alpha ignored)
    - `["a { color: hsl(0, 100%, 50%); }"]` -> hex: "#ff0000"
    - `["a { color: hsl(360, 100%, 50%); }"]` -> hex: "#ff0000" (hue wraps)
    - `["a { color: hsl(0, 0%, 100%); }"]` -> hex: "#ffffff" (pure white)
    - `["a { color: hsl(0, 0%, 0%); }"]` -> hex: "#000000" (pure black)
    - `["a { color: cornflowerblue; }"]` -> hex: "#6495ed" (named color)
    - `["--color-primary: #6C5CE7;"]` -> `[{ value: "#6C5CE7", hex: "#6c5ce7", varName: "--color-primary" }]`
    - Duplicate hex values deduplicated: `["a{color:#f00} b{color:#ff0000}"]` -> 1 result
    - Empty CSS -> empty array

    ## Font Extraction (extractFonts)
    - Input: `string[]` (array of CSS text content)
    - Output: `string[]` (unique font names, generic families filtered out)

    Cases:
    - `['body { font-family: "Inter", sans-serif; }']` -> `["Inter"]`
    - `['h1 { font-family: "Playfair Display", Georgia, serif; }']` -> `["Playfair Display", "Georgia"]`
    - `['p { font: 16px/1.5 "Roboto", Arial, sans-serif; }']` -> `["Roboto", "Arial"]` (shorthand)
    - `['a { font-family: monospace; }']` -> `[]` (generic-only filtered)
    - Duplicates across multiple CSS texts deduplicated

    ## Visible Text Extraction (extractVisibleText)
    - Input: `string` (HTML)
    - Output: `string` (visible text, collapsed whitespace, max 10KB)

    Cases:
    - `"<body><p>Hello world</p></body>"` -> `"Hello world"`
    - `"<body><script>var x=1;</script><p>Text</p></body>"` -> `"Text"` (script stripped)
    - `"<body><style>.x{}</style><p>Text</p></body>"` -> `"Text"` (style stripped)
    - `"<body><nav>Nav</nav><main>Main</main></body>"` -> `"Main"` (nav stripped)
    - Text longer than 10000 chars truncated to 10000
    - Whitespace collapsed: `"  Hello   world  "` -> `"Hello world"`

    ## Embedded Styles (extractEmbeddedStyles)
    - Input: `string` (HTML)
    - Output: `string[]` (CSS text from each `<style>` block)

    Cases:
    - `"<style>.x { color: red; }</style>"` -> `[".x { color: red; }"]`
    - `"<style>a{}</style><style>b{}</style>"` -> `["a{}", "b{}"]`
    - `"<html><body>no styles</body></html>"` -> `[]`

    ## Hex Normalization (normalizeToHex)
    - Input: `string` (any CSS color value)
    - Output: `string | null` (6-digit hex or null if unparseable)

    Cases:
    - `"#fff"` -> `"#ffffff"`
    - `"#abcdef"` -> `"#abcdef"`
    - `"rgb(0, 128, 255)"` -> `"#0080ff"`
    - `"hsl(120, 100%, 50%)"` -> `"#00ff00"`
    - `"red"` -> `"#ff0000"`
    - `"notacolor"` -> `null`
  </behavior>
  <implementation>
    Create `src/tokenExtraction.ts` with:

    1. **NAMED_COLORS** const map — all 148 CSS named colors mapped to hex (copy from MDN reference, as described in RESEARCH.md)

    2. **Regex constants** (from RESEARCH.md code examples):
       - `HEX_RE` for hex colors
       - `RGB_RE` for rgb/rgba (both comma and space syntax per Pitfall 2)
       - `HSL_RE` for hsl/hsla (both comma and space syntax)
       - `CSS_VAR_COLOR_RE` for custom properties with color values
       - `FONT_FAMILY_RE` and `FONT_SHORTHAND_RE` for font declarations
       - `NAMED_COLOR_RE` built from NAMED_COLORS keys

    3. **normalizeToHex(value: string): string | null** — dispatches to expandHex, rgbToHex, hslToHex, or NAMED_COLORS lookup. Returns lowercase 6-digit hex.

    4. **expandHex(hex: string): string** — 3-digit to 6-digit, strips alpha from 4/8-digit (per RESEARCH.md code example)

    5. **rgbToHex(r, g, b): string** — clamp 0-255, to hex (per RESEARCH.md code example)

    6. **hslToHex(h, s, l): string** — normalize hue mod 360, s/l divide by 100, standard conversion (per RESEARCH.md code example). Edge cases: hsl(0,0%,100%) = white, hsl(0,0%,0%) = black (Pitfall 3).

    7. **extractColors(cssTexts: string[]): RawColor[]** — scan all CSS texts with all color regexes, normalize each to hex, capture varName from CSS_VAR_COLOR_RE matches, deduplicate by hex (keep first occurrence)

    8. **extractFonts(cssTexts: string[]): string[]** — scan with FONT_FAMILY_RE and FONT_SHORTHAND_RE, parse comma-separated font stacks with `parseFontFamilies`, filter generic families, deduplicate

    9. **extractVisibleText(html: string): string** — DOMParser, remove script/style/nav/footer/header/noscript/svg/iframe elements, get body.textContent, collapse whitespace, trim, truncate to 10000 chars

    10. **extractEmbeddedStyles(html: string): string[]** — DOMParser, querySelectorAll('style'), collect textContent

    Export: `RawColor` interface, `extractColors`, `extractFonts`, `extractVisibleText`, `extractEmbeddedStyles`, `normalizeToHex`

    Test file uses `// @vitest-environment jsdom` directive (for DOMParser) and standard vitest imports.
  </implementation>
