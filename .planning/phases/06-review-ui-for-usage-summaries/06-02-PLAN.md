<feature>
  <name>filterUsageSummary</name>
  <files>src/usageSummaryFilter.ts, src/usageSummaryFilter.test.ts</files>
  <behavior>
    filterUsageSummary(summary: string, deselectedTokens: Array<{ name: string; value: string }>): string

    The function takes a usage summary string and an array of deselected token identifiers (name + value pairs).
    For each deselected token, it removes sentences that reference the token's name OR value.
    A "sentence" is text ending with a period, exclamation mark, or end-of-string.

    Cases:
    - No deselected tokens -> returns original summary unchanged
    - Empty summary -> returns empty string
    - One deselected token referenced in one sentence -> that sentence removed, remaining text intact
    - Token name appears ("Primary") -> sentence containing it removed
    - Token value appears ("#5C4EFA") -> sentence containing it removed
    - Multiple deselected tokens in same sentence -> sentence removed once
    - All sentences reference deselected tokens -> returns empty string
    - Token name is substring of another word (e.g., "Base" in "database") -> still matches (acceptable tradeoff for simplicity; token names from AI are typically distinctive)
    - Trailing/leading whitespace cleaned up after removal
  </behavior>
  <implementation>
    Split summary into sentences (split on `. ` or `.` at end, preserving delimiters).
    For each sentence, check if it contains any deselected token's name or value (case-insensitive).
    Keep only sentences that do NOT reference any deselected token.
    Rejoin with spaces and trim.

    Integration in ReviewView.tsx:
    - Keep the raw `usageSummaries` state (from initial) as the "source of truth"
    - Compute `displayedSummaries` via useMemo that applies filterUsageSummary based on deselected tokens per category
    - The textarea displays `displayedSummaries[category]` but on edit, updates raw `usageSummaries[category]`
    - When user edits, the edited text becomes the new source of truth for that category
    - The onApply callback passes the DISPLAYED (filtered) summaries, not the raw ones
  </implementation>
</feature>

```typescript
const displayedSummaries = useMemo(() => {
  const deselectedColors = colors.filter(c => !selected[c.id]).map(c => ({ name: c.name, value: c.hex }));
  const deselectedFonts = fonts.filter(f => !selected[f.id]).map(f => ({ name: f.role, value: f.value }));
  const deselectedRadii = radii.filter(r => !selected[r.id]).map(r => ({ name: r.label, value: r.value }));
  const deselectedSpacing = spacing.filter(s => !selected[s.id]).map(s => ({ name: s.label, value: s.value }));

  return {
    colors: filterUsageSummary(usageSummaries.colors, deselectedColors),
    fonts: filterUsageSummary(usageSummaries.fonts, deselectedFonts),
    radii: filterUsageSummary(usageSummaries.radii, deselectedRadii),
    spacing: filterUsageSummary(usageSummaries.spacing, deselectedSpacing),
  };
}, [usageSummaries, colors, fonts, radii, spacing, selected]);
```
