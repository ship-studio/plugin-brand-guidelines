  <name>Task 1: Pure merge functions with tests</name>
  <files>src/reviewMerge.ts, src/reviewMerge.test.ts</files>
  <behavior>
    - prepareTokens(analysis: AnalysisResult) returns { colors: BrandColor[], fonts: BrandFont[], voiceNotes: string } with crypto.randomUUID() IDs
    - mergeTokens(existing: BrandSettings, accepted: { colors: BrandColor[], fonts: BrandFont[], voiceNotes: string | null }) returns updated BrandSettings
    - mergeTokens appends accepted colors to end of existing colors array
    - mergeTokens appends accepted fonts to end of existing fonts array
    - mergeTokens replaces voice notes when existing is empty string
    - mergeTokens appends voice notes with double newline separator when existing is non-empty
    - mergeTokens passes null voiceNotes leaves existing unchanged
    - mergeTokens preserves assets, targetFile, lastExportedHash unchanged
    - prepareTokens handles empty arrays gracefully
  </behavior>
  <action>
    Create `src/reviewMerge.ts` with two pure functions:

    1. `prepareTokens(analysis: AnalysisResult)` -- converts AnalysisResult (no IDs) into BrandColor[] and BrandFont[] (with IDs via crypto.randomUUID()) and voiceNotes string. This is the conversion from AI output to editable review state.

    2. `mergeTokens(existing: BrandSettings, accepted: { colors: BrandColor[], fonts: BrandFont[], voiceNotes: string | null })` -- returns a new BrandSettings with accepted tokens appended. Colors append, fonts append, voice notes: replace if existing empty, append with `\n\n` separator if existing non-empty, null means no change.

    Create `src/reviewMerge.test.ts` with vitest tests covering all behaviors listed above. Write tests FIRST (red), then implement (green).
  </action>
